## 3. 结论（L2 收益模式）

1. **TTFT 收益不稳定**：仅 2/9 压测档显著改善（rt-32c@4 -30.5%、mini-64c -19.6%）；
   其余档持平或劣化（mini-32c +43.9% 最差——低并发下 L2 写回开销 > 收益）。
2. **TPOT 普遍略优（-1.5~-14.4%，7/9 档改善）**：L2 减少 prefill 侧排队/抖动，decode
   侧更顺——这是被忽视的隐性收益。
3. **吞吐有增有减**（-6.1%~+7.9%），无系统性方向。
4. **multiturn 冷→热转换轮（round1）改善显著（-51~-73%）**：L2 的核心价值场景
   （真实多轮对话中首轮后命中）。但**官方案例（parallel4 小并发）下 L2 略劣**——
   工作集小（4 并发×2K），L1 已足够，L2 只贡献开销。
5. **综合判定**：L2 收益**场景相关**——建议面向"**多轮对话/共享前缀**"场景启用
   （round1 大优），纯随机短请求高并发场景（mini-32c 类）禁用；生产切换与否取决于
   业务负载画像（若以多轮对话为主 → 值得切；纯短请求 → 最优解非 HiCache 即可）。
